# VARUNA GRID — Honesty Ledger

Every element a judge can see on screen, and what it actually is. Updated by every phase of
`scalable-coalescing-hammock.md` that touches a row — this file is also the artifact to hand a
judge directly.

**Vocabulary**
- **REAL** — computed from real pipeline logic/data, currently wired end to end.
- **SIMULATED** — computed by a real algorithm running on synthetic/replay input (labelled as such).
- **RECONSTRUCTION** — a real-world historical fact, not computed by VARUNA (must never carry a score).
- **NOT_CONFIGURED** — a real capability with no credential/infra behind it in this environment.
- **DECORATIVE** — presented as if live/meaningful but is a literal, mock array, or dead code path.
- **BROKEN** — advertised as working but errors/404s/produces impossible values. Bug, not category.
