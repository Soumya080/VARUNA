# VARUNA GRID — dependency manifest
#
# This file deliberately contains no pinned packages. `pyproject.toml` is the
# single source of truth for dependencies.
#
# It used to carry its own hand-maintained list, which silently drifted out of
# sync: it was missing reportlab, pyjwt, argon2-cffi, xgboost, prometheus-client
# and the opentelemetry packages. Anyone who installed with
# `pip install -r requirements.txt` got an environment where login returned 500
# and the PDF report route crashed — while the same code worked fine for anyone
# who used `pip install -e .`. That failure mode cost a teammate real debugging
# time, so the list is gone rather than re-synced.
#
# Installing via this file still works and now resolves through pyproject:
#
#     pip install -r requirements.txt      # equivalent to: pip install -e .
#
# Optional extras (not installed by the line below):
#     pip install -e ".[ml]"     torch / torchvision / smp / mlflow / onnxruntime
#     pip install -e ".[e2e]"    playwright, for scripts/judge_test.py
#
# OpenDrift resolves poorly on pip. Prefer:
#     conda install -c opendrift -c conda-forge opendrift

-e .
